# 五行与十神

## 五行表达

将五行作为传统命理中的性格和做事方式观察框架，而非科学因果或医学结论。

- 木：规划、成长、学习、人际经营。
- 火：表达、曝光、行动、主动争取。
- 土：稳定、执行、流程、储备、长期积累。
- 金：标准、边界、判断、纪律、结果意识。
- 水：信息、沟通、复盘、弹性、适应变化。

仅当统计值为零时说“缺”。统计较少时说“偏弱”；统计多但未造成明显失衡时说“相对偏旺”。建议应低风险且具体，例如建立预算、规范流程、训练表达、改善作息、加强复盘。不要建议购买开运物、改名、做法事、借贷或高风险投资。

## 十神白话

只选命盘最关键的 2-4 项解释。每项都说明：它是什么、现实中的优势、过头时的表现和一个可执行建议。

| 十神 | 通俗解释 | 现实例子与提醒 |
| --- | --- | --- |
| 比肩 | 同辈、同行、伙伴与自我主张。 | 有主见、肯扛事；过头会和伙伴争强。合作前明确分工。 |
| 劫财 | 竞争、人情往来、共同资源。 | 机会来自关系，也容易因合伙或面子花钱。借款、担保、分成要留书面记录。 |
| 食神 | 技能输出、表达、产品和服务。 | 适合把经验做成作品、内容或可交付服务；忌只追舒服不落地。 |
| 伤官 | 创新、质疑、突破旧方法。 | 能改善低效流程；表达太冲会和规则或上级冲突。先给方案，再提问题。 |
| 正财 | 稳定收入、预算、可持续回报。 | 适合做交付、回款、储蓄和长期客户；忌只看流水不看利润。 |
| 偏财 | 项目、人脉、市场机会与额外收入。 | 适合拓客、谈项目和副业；先看回款与退出条件，不追热闹项目。 |
| 正印 | 正规学习、老师、平台和成熟方法。 | 适合考证、进修、标准化；忌只学习不实践。 |
| 偏印 | 非标准学习、直觉、研究和独立判断。 | 适合策略、研究和复杂问题；忌想太久不交付。 |
| 正官 | 规则、职位、责任、信用和正式认可。 | 适合晋升、考证和正规平台；流程、合同和合规是助力。 |
| 七杀 | 压力、竞争、难题与挑战性责任。 | 能逼出执行力和主导权；忌硬扛、冲动扩张。用数据、流程和阶段目标减压。 |

不要说某十神必然对应一段婚姻、某项疾病或某个具体职业。它只提供解读角度，必须和原局、年龄阶段和现实信息共同判断。
