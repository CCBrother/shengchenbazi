# 八字命理解读

执行本地排盘后，再做解释；不要凭日期手算日柱或大运。

## 输入

收集公历或农历日期、小时和分钟、性别、出生地。允许用户额外给出事业状态，例如创业阶段、事业有成、上班、公务员、事业单位、打零工或失业中。

- 时辰不确定时，明确说明时柱会影响细节；可按用户给出的候选时辰分别排盘，但不要把推测时辰当事实。
- 出生地若只用于记录，应如实说明未校正真太阳时；如果要校正，必须先取得精确地点和采用规则。
- 事业状态只作为现实背景，用来细化事业、财运与行动建议，不可倒推命盘或编造经历。

## 排盘

1. 优先使用可验证的历法库。JavaScript 项目使用 `lunar-javascript` 的 `Solar`、`Lunar`、`getEightChar()` 与 `getYun()`；Python 项目选择等价且已验证的库。
2. 输出年、月、日、时四柱，标明日主、十神、藏干、五行统计、生肖、星座和农历/公历日期。
3. 大运按性别、年干阴阳、节气与流派换日规则计算。说明起运年龄、顺逆排和每步大运的起止年份。
4. 用至少一个已知日期测试四柱与流年结果，再交付页面或报告。

## 解读原则

- 将八字当作传统文化的结构化自我观察，不把判断说成事实、保证或医疗/投资建议。
- 讲清有利面、代价、风险和可执行建议。避免只说好话，也避免死亡、灾祸、具体疾病等恐吓式内容。
- 先看原局，再结合大运和用户指定流年。不要用流年结论替代一生命局判断。
- 事业、财富、感情家庭、健康节奏、子女、父母、贵人、学业都应覆盖；根据命盘增加性格、人际、合作或阶段重点。
- 健康只给规律作息、压力管理和就医提醒；不从五行推断疾病或人体器官。

## 五行与十神

必须读取 [五行与十神](references/elements-and-ten-gods.md)。

- 五行数量为零才称“缺”；数量较少称“偏弱”，不可混用。
- 有缺失或偏弱时，给低风险的学习、工作方法、作息、环境与沟通建议；明确不建议通过昂贵摆件、迷信消费或冒险决定来“补”。
- 无明显缺失时，直接说明无需刻意补，重点是平衡和节奏。
- 对关键十神使用白话翻译与现实例子。不要仅堆砌“比肩、偏印、七杀”等术语。

## 输出

先给简短总览，再按以下顺序组织内容；按需要合并，不重复页面已展示的四柱表。

1. 八字排盘详解：解释日主、月令、关键组合和藏干。
2. 命局核心特征：给优势、风险和应对方式。
3. 五行平衡与补偏建议：明确缺失、偏弱、均衡或偏旺。
4. 十神白话解释：选 2-4 个最关键十神，说明好处、过头时表现和现实例子。
5. 大运走势：按阶段说明主题、机会和注意事项。
6. 一生运势：事业、财富、夫妻感情、健康节奏、子女、父母、贵人、学业。
7. 指定年份流年：解释干支、与原局/大运的关系、机会、风险和行动重点。
8. 关键年份提醒与总结。

网页或 API 集成需读取 [结构化输出](references/structured-output.md)，并要求模型严格返回 JSON。将模型返回视为不可信输入：校验字段、限制长度、JSON 解析失败时重试一次；前端不要显示模型品牌或原始技术错误。

## 交付检查

- 核对四柱与输入历法、时区、换日规则一致。
- 检查“五行缺失”和“偏弱”用词正确。
- 检查关键十神均有白话解释，而不是术语堆砌。
- 检查每项包含机会、风险和现实建议。
- 检查不含死亡断语、疾病诊断、确定性承诺或虚构的经历。
